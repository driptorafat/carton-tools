Method note

For each container, the tool tests all 6 rotations of your carton and picks the orientation that fits the most boxes using simple grid stacking (floor(container ÷ box) along each axis — no mixed orientations or interlocking). This mirrors how most freight forwarders estimate container loads. Actual counts can be a bit higher with mixed-orientation ("brick") packing, or lower once dunnage, pallets, and door-swing clearance are factored in. If you enter a carton weight, the box count is also capped by the container's typical max payload.

Method note

RSC method (most common corrugated box style) estimates the flat blank/sheet needed to die-cut the box: blank length = 2 × (L + W) + glue flap; blank width = H + W. Simple method just sums the box's total outer surface area: 2×(L·W + L·H + W·H). This under-estimates real board usage for corrugated RSC boxes since it ignores flaps, but is useful for folding-carton or wrap-style costing. The waste % accounts for trim, print bleed, and press setup loss. Final cost = board area (sq ft) × (1 + waste%) × price per sq ft.

SQM method is for a 2-piece telescoping box (separate lid + base, common for garment/gift boxes): blank A = L + W + flap 1, blank B = W + H + flap 2, SQM per piece = (A × B) ÷ 10,000, SQM per box = SQM per piece × pieces per box (2 for lid+base, 1 for a single flat panel), then cost = SQM per box × price per SQM. No waste % is applied — it mirrors a mill costing sheet exactly.
